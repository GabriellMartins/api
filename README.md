# Kodex ERP API

API desenvolvida em **Kotlin** como parte do Kodex ERP, um projeto que tinha como objetivo se tornar um sistema de gestão empresarial completo, composto por diversos módulos.

Durante o desenvolvimento, criei e testei diferentes versões do projeto. Entre elas, esta API em Kotlin foi a que mais se destacou em estrutura e organização. Foram alguns meses de trabalho, estudo e dedicação até chegar a esta versão.

Embora o projeto não tenha alcançado o resultado final que eu esperava, decidi disponibilizar seu código publicamente para que outras pessoas possam:

- Estudar a arquitetura e a organização da API;
- Utilizar o código como referência em outros projetos;
- Adaptar funcionalidades para suas próprias aplicações;
- Contribuir com melhorias e novas implementações;
- Aprender com as decisões e soluções adotadas durante o desenvolvimento.

> **Importante:** este repositório contém somente a API do Kodex ERP. A aplicação completa e os demais componentes do sistema não estão incluídos.

## Sobre o projeto

A estrutura da API foi planejada com foco em **organização, separação de responsabilidades e facilidade de manutenção**.

O projeto pode ser útil para quem procura uma referência de organização para APIs desenvolvidas em Kotlin.

Como se trata de um projeto antigo e descontinuado, alguns trechos podem precisar de atualizações, correções ou adaptações antes de serem utilizados em produção.

## Objetivo da publicação

Estou liberando este código porque acredito que ele ainda pode ser útil para a comunidade.

Mesmo sem ter concluído o ERP, o trabalho desenvolvido pode servir como ponto de partida, material de estudo ou inspiração para novos projetos.

Sinta-se à vontade para explorar, estudar, modificar e adaptar o código de acordo com suas necessidades.

## Contribuições

Contribuições são bem-vindas. Caso queira colaborar:

Sugestões, correções e melhorias também podem ser registradas por meio das *issues* do repositório.
